tapedup-payment-rules: one-time setup

Each panel below activates one Shopify Function from this app. You only need to run each once — after that, the rule lives in Shopify and this page is done for it. Safe to reload or come back later; each panel checks whether it's already set up before offering to create anything.

Hide trade-account payment method

Hides "Trade Account – Invoice / Net Terms" from checkout for everyone except customers tagged "terms".

B2B trade pricing

    
Applies each product's custom.wholesale_price metafield (or a flat fallback %) as an automatic discount for customers tagged "b2b" — replaces creating a matching discount by hand per product. Set to combine with your other automatic discounts (e.g. Buy 4 get 1 free) so dealers get both at once.

B2B shipping: hide other rates

    
For customers tagged "b2b", keeps only the cheapest delivery option — plus a "Priority" one if you've created a rate with that word in its name — visible at checkout, and hides everything else, so they see their trade rate and an optional paid priority upgrade, not a full carrier-rate list.
